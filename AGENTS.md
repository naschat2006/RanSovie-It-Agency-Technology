# Project Development Guidelines & User Directives

## Core Principles

1. **Precision & 100% Accuracy Over Speed**:
   - The user prioritizes perfection, complete accuracy, high craft, and robust implementation over quick or rushed deliveries.
   - Take the time necessary to thoroughly inspect, verify, test, and polish every single detail.
   - Zero tolerance for superficial placeholders, broken links, sloppy styling, or unfinished stubs.

2. **Quality Standards**:
   - Verify every UI element across both desktop and mobile responsiveness.
   - Ensure color contrast, typography scale, padding math, and micro-interactions adhere strictly to design excellence.
   - Always run verification and lint checks before finalizing any step.
